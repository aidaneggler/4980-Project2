## Playtest Feedback

After the first playtest I made several changes to improve the game based on the feedback. One of the biggest issues was that players weren't always sure what the controls were or what they were supposed to do. I added a main menu with a controls screen. Players can also press Tab during gameplay to view the controls if they forget something.

I also added a HUD that shows which flashlight the player currently has equipped. I added on-screen messages for important interactions, such as picking up a flashlight, activating a switch, or unlocking a door. These messages were only displayed in the Unity debug console. This gives players better feedback and makes it easier to understand when they've successfully done something.

Another change was adding a small amount of ambient lighting to the rooms. The rooms were almost completely dark without a flashlight and that made navigating difficult. I wanted to keep the dark atmosphere while still allowing players to see enough of their surroundings to explore.

## Exploring the Mechanic

The main mechanic of my game is using different wavelengths of light to reveal hidden objects and solve puzzles. I wanted to explore how this mechanic could be used in different situations rather than having every puzzle work the same way.

I expanded the game into two levels with different gameplay styles. The first level is a puzzle room where players learn how the different flashlights work. They use UV light to reveal a hidden code and red light to find a hidden switch. This level introduces the mechanics in a smaller environment.

The second level is a maze that focuses more on exploration. Players must navigate the maze and find three buttons that are only visible under red light. Once all three buttons are activated, the exit opens. This makes players use the same light mechanic in a larger environment where finding the objects is part of the challenge.

I also added 3D models for the flashlight pickups to make the different light sources feel more like actual items that players collect.

I wanted the changes to make my game easier to understand while keeping the focus on experimenting with different lights. The two levels show how the same mechanic can be used for both individual puzzles and exploration.
